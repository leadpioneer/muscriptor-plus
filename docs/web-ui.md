# Веб-интерфейс

Веб-интерфейс — это тот же UI, что и на демо-сайте, только собранный локально
и раздаётся самим сервером `muscriptor serve` по адресу
<http://127.0.0.1:8222>. Он доступен на русском и английском (переключатель
**EN / RU** в шапке; выбор сохраняется в браузере, при первом визите язык
берётся из настроек браузера).

Экран один из двух: **загрузка** и **транскрипция**. Пока сервер думает или
занят, вы остаётесь на экране загрузки.

## Экран загрузки

- Перетащите аудиофайл в любое место страницы или нажмите «Выбрать
  аудио-файл». Поддерживаются MP3, WAV, FLAC, OGG, M4A, AIFF, Opus и другие
  форматы libsndfile.
- «Попробуйте пример трека» подставляет демо-запись (композиция Headache by
  Lost Deposit) и разумный набор инструментов — просто нажмите «Расшифровать».
- Блок «Какие инструменты есть в этом треке?» (необязательный): выбранные
  группы инструментов становятся **жёстким ограничением** — всё, что не
  указано, не появится в результате. Пустой список — модель определяет состав
  сама. Названия — из [списка в cli.md](cli.md#список-инструментов).
- Галочка **«Удалить ведущий вокал перед транскрипцией»** (по умолчанию
  выключена) запускает разделение на вокал/инструментал и расшифровывает
  инструментал. См. [ниже](#удаление-ведущего-вокала).
- Ссылка «или сделайте ноты из готового MIDI-файла» — загружает **MIDI** (не
  аудио) и сразу гравирует ноты через `/sheets`. Модель не участвует, поэтому
  это работает, даже когда сервер занят транскрипцией.
- Кнопка **«Исправить аппликатуру»** открывает гитарную лабораторию — можно
  загрузить любой `.mid`/`.midi` без всякой транскрипции (см.
  [guitar-arranger.md](guitar-arranger.md)).
- Если сервер недоступен, вместо выбора файла появится сообщение
  «недоступен». Если файл не декодируется, ошибка показывается рядом с
  выбором файла, и можно выбрать другой.

Пока запрос ждёт своей очереди, кнопка «Расшифровать» показывает статус:
«Расшифровываем…» (запрос ушёл) или «Серверы заняты, повтор через N с» —
клиент сам повторяет попытку каждые 5 секунд, пока сервер не освободится.
Отменить ожидание можно ссылкой «Отмена».

## Экран транскрипции

После того как сервер принял запрос, открывается интерактивный piano roll:

- ноты появляются по мере генерации, каждая — со своим цветом инструмента;
- фон подсвечивает доли такта, если темп определён; временная шкала
  переключается с секунд на такты;
- кнопки **Играть/Пауза** (или клавиша **Пробел**), **Следовать за
  курсором** (прокрутка за playhead; ручная прокрутка отключает следование,
  пока вы не вернётесь к живой границе);
- ползунки громкости: **Общая**, **Оригинал**, **MIDI**, **Стерео**
  (разносит оригинал и синтез по каналам);
- список инструментов справа: клик по ползунку — громкость, кнопки
  **S** (solo) и **M** (mute), наведение мышью подсвечивает ноты инструмента
  в ролле. Инструменты, которые вы указали, но модель не нашла, показаны
  серыми зачёркнутыми.

Внизу — прогресс: полоса с оценочным временем («0:42/3:10, готово через
1:05») и названия стадий, когда включено удаление вокала: «Подготовка
аудио…», «Удаление ведущего вокала…», «Подготовка инструментала…»,
«Транскрипция инструментала…», «Создание MIDI…».

## Скачивания

Меню **«Скачать»** на экране транскрипции:

| Пункт | Что это |
|---|---|
| «Файл MIDI» | `.mid` с темпом и размером (если темп найден) |
| «WAV — только расшифровка» | MIDI, синтезированный FluidSynth, моно |
| «WAV — стерео с оригиналом» | слева оригинал, справа синтез |
| «Нотный лист» | PDF/MusicXML через MuseScore на сервере (см. ниже) |
| «Вокал (WAV)» / «Инструментал (WAV)» | только после прогона с удалением вокала |

Ноты готовятся на сервере одним пакетом (это медленно — десятки секунд) и
возвращаются zip-архивом; диалог «Скачать ноты» сразу показывает файлы внутри:
`score.mid`, `score.musicxml`, `full_score.pdf` и PDF по инструментам (с
табулатурами для ладовых). Можно скачать любой файл отдельно или весь архив
кнопкой «Скачать всё». Если устойчивый ритм не найден, диалог предупреждает,
что тактовые черты — догадка (ноты гравировались без квантования).

> Для нот и PDF-табулатур на машине, где работает сервер, должен быть
> установлен **MuseScore 4+**. Без него остальные скачивания работают, а ноты
> и `/sheets`, и кнопка PDF в гитарной лаборатории вернут ошибку 503 с
> подсказкой.

## Удаление ведущего вокала

Галочка на экране загрузки (прогон с ней не откатывается на оригинал при
ошибке). После завершения:

- в меню скачивания появляются оба стема;
- рядом с ползунком «Оригинал» появляется переключатель
  **Оригинал / Инструментал / Вокал** — что слышно в предпросмотре.
  По умолчанию после такого прогона включён **«Инструментал»**: слышимое
  совпадает с тем, по чему снята партитура. Таймлайн стемов совпадает с
  оригиналом;
- над меню скачивания появляется пометка, что транскрипция сделана по
  инструменталу.

Стемы хранятся на сервере ограниченное время (по умолчанию час), после чего
недоступны; браузер кэширует уже загруженные копии, пока открыта вкладка.

## Переключатель модели (шапка)

Выпадающий список **Модель** показывает текущий размер и работает без
перезагрузки страницы:

- выбор `small` / `medium` / `large` запускает фоновую загрузку; пока идёт
  загрузка, список заблокирован («загружается…»), а транскрипция отклоняется
  с 409;
- кнопка **«выгрузить»** освобождает VRAM вручную; состояние «выгружена»
  показывает кнопку **«загрузить»**, а любой следующий запрос (транскрипция
  или смена модели) также загрузит модель сам;
- при ошибке загрузки (например, истёк доступ к HF) показывается «ошибка
  загрузки» и кнопка **«повторить»** — список остаётся работоспособным;
- если сервер не поддерживает переключение, список просто скрыт.

## Гитарная лаборатория аппликатуры

Открывается кнопкой **«Исправить аппликатуру»** — и на экране загрузки
(принимает любой MIDI-файл), и после транскрипции (берёт MIDI результата, без
повторной загрузки). Полное описание — в
[guitar-arranger.md](guitar-arranger.md); кратко:

- выбор дорожки, если в файле их несколько;
- партия автоматически приводится к стандартному строю (транспозиция
  опущенных записей, удаление внедиапазонных октавных дублей); сдвиг виден в
  метриках, а при отказе — понятная ошибка (UI использует серверные значения
  по умолчанию; `--no-normalize` доступен только в CLI/API);
- навигация по фразам и нотам (стрелки), SVG-гриф с допустимыми позициями;
- клик по позиции фиксирует ноту (lock) и пересчитывает всю фразу; повторный
  клик или «Снять фиксацию» — снимает;
- прослушивание на условных 120 BPM (в документе нет карты темпа), метрики
  эргономики, выбор мелодической политики (все ноты / верхняя / нижняя);
- скачивания: `arrangement.json`, `arrangement.mid`, ASCII-таб (`.txt`),
  MusicXML и ZIP с PDF (ноты + табулатура) — последний требует MuseScore на
  сервере. MusicXML и PDF содержат **джазовые обозначения аккордов** над
  нотоносцем; цифры пальцев левой руки не выводятся (позиции струн/ладов
  видны в табулатуре).

## Прочее

- **Язык** переключается в шапке в любой момент; инструменты, стадии и FAQ
  переводятся, имена скачиваемых файлов остаются английскими.
- **Горячая клавиша**: Пробел — играть/пауза (если фокус не в поле ввода).
- **Перетаскивание файла на экран транскрипции** спросит подтверждение,
  сбросит текущий результат и вернёт на экран загрузки с новым файлом.
- Клик по логотипу на экране транскрипции равносилен «Расшифровать другой
  файл» (с подтверждением).
